# 开发与验证

先按 [README](../README.md) 安装项目依赖。前端开发检查需要 Node.js 24；Node.js 依赖只用于开发测试，运行面板不需要构建步骤。

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -p "test_*.py" -v
.\.venv\Scripts\python.exe -B tests/runtime_smoke.py
.\.venv\Scripts\python.exe -B scripts/audit_release.py
npm ci --ignore-scripts
npm test
npm run test:browser
```

单元测试覆盖独立凭据、配置快照、跨进程保存冲突、来源校验、对话隔离、归档恢复、列表及结果分页、日志清理的预览与路径保护、取消与超时、工具权限及 worktree 隔离。原生集成测试用真实 SDK 和运行组件连接本地模拟接口，验证三种代理的「读取 → 工具结果 → 回复」、文件写入及命令执行，检查实际进度与只读工具集；使用假 Key，不消耗模型服务额度。

`npm test` 用 jsdom 和延迟响应覆盖状态与请求竞态；`npm run test:browser` 默认使用本机 Edge，也可用 `BROWSER_EXECUTABLE` 指定 Chromium 系浏览器的可执行文件。浏览器检查覆盖 320、375、480、760、1024px 的任务页面、五个设置子页及展开的归档区域，检查页面实际可见、键盘与滚动交互，以及 axe 自动扫描；不替代人工读屏测试。模拟截图与检查记录保存在被 Git 忽略的 `outputs/validation/`。修复对应关系见 [审查修复清单](review-fixes.md)。

GitHub Actions 在 Windows、Python 3.11 / 3.14 上执行后端检查，另设 Node.js 24 前端检查任务。模拟接口验证的是本项目与固定 SDK 的集成，不代表某个第三方中转服务已通过验证。

欢迎通过 Issue 或 PR 提交最小复现和改进；请先运行上述检查，勿附带真实 Key、访问令牌、会话日志或个人路径。

配置同步测试使用隔离的用户目录与假凭据，覆盖默认关闭、单次导入、跟随、字段冲突、来源变化、认证与协议识别；规则测试覆盖顺序、AND 条件、意图匹配、候选绑定、过期与配置版本、启动前回退及并发上限。前端测试覆盖规则草稿、同步选择和迟到试选响应。

连接完整性回归还覆盖环境变量优先级、仅跟随 Key 时的服务商切换、旧跟随状态复查、写入失败回滚和读写线程竞争。大结果检查使用超过 2 MiB 的 Unicode/CRLF 文本，验证重启后完整分页、旧格式兼容、写入失败保留旧结果及归档/日志清理后的内容不变。日志清理检查包含冷缓存和部分缓存下的多批次读取。

## Markdown 预览

面板使用固定版本的 `markdown-it` 浏览器文件，存放于 `vendor/`，由本地面板同源提供；用户运行时无需 Node.js、网络下载或前端构建。升级解析器时更新精确版本和 lockfile，再生成随包文件及许可：

```powershell
npm run vendor:markdown
npm test
npm run test:browser
```

`npm test` 首先逐字节核对随包脚本、许可与已安装依赖。解析禁用原始 HTML，保留默认链接协议校验，图片仅显示转义后的说明文字。结果缓存始终保留原文，只有文本或显示模式变化时更新预览节点。前端回归覆盖常见 Markdown、危险内容、原文切换、跨页引用、逐字复制以及轮询选区；真实浏览器检查窄屏长表格/代码块、键盘焦点、剪贴板与 axe。

新记录将结果保存为任务目录下的 `result-<SHA256>.txt`，`job.json` 保存引用与字符数，先写结果再发布元数据。旧版内联结果仍可直接读取，不自动改写历史；新的引用格式需使用升级后的服务。历史列表只读元数据，详情按字符分页；日志清理不会删除结果文件。失败写入可能留下未引用的结果副本，保留数据优先。升级后需重启 MCP 和独立面板服务，重新打开面板以载入新脚本。

## 应用设置

`settings-schema.json` 是运行/界面偏好的字段、默认值、范围与文案来源。`app_settings.py` 负责加载、跨进程版本冲突和原子保存；新任务将预算快照传给 worker 及三个适配器，并在历史中保留。不要把当前设置套到已有任务的预算显示。新增字段需同时连接实际使用处，不能只添加输入框。

设置回归使用临时状态目录与假 Key：真实 HTTP 保存后调整并发准入、验证已有任务不被取消、单次超时覆盖和结果分页、子进程读取持久化设置、旧版本保存冲突、写入失败保留旧值、环境覆盖、所有字段类型/范围，以及三个真实 SDK 配置对象与活动预算。前端覆盖独立草稿、迟到配置响应、恢复默认值、键盘子标签页及设置后的实际分页/刷新。完整选项和保留的内部边界见 [应用设置](application-settings.md)。
