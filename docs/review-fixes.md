# 前端与 UI 审查修复清单

对应 2026-11-03 Claude Opus 5.5 前端审查、Gemini 4 Argon UI 审查及独立复核；基线为 `81b6b38`。本次按复核确认的功能问题实施修复，保留原生 JavaScript，不引入前端框架。

| 问题 | 修复 | 回归证据 |
| --- | --- | --- |
| 任意任务轮询导致当前详情重绘，选区、焦点与等待状态丢失 | 按任务保留节点和操作状态，仅更新变化文本；离开任务时记录滚动位置 | jsdom 选区/焦点/等待操作检查；Edge 选区与滚动检查 |
| 强制刷新被正在进行的请求吞掉 | 将强制刷新排队，暂停自动刷新时也执行；旧请求返回后补发 | 延迟旧快照期间提交新任务 |
| 所选任务离开最近 50 条记录后仍显示旧操作区 | 清空旧详情，显示任务不在当前列表中的说明 | 移除选中任务后检查按钮消失 |
| 取消失败信息出现在其他任务 | 错误和取消等待状态按任务 ID 保存 | 延迟取消响应并切换任务 |
| 旧面板或 MCP 模型选择覆盖新配置 | 每个代理独立版本；保存时比较版本并返回 409；跨进程事务锁保护比较与写入 | HTTP 冲突及密钥未被覆盖检查；两个独立解释器并发保存 |
| 后台配置刷新覆盖草稿或已成功保存的内容 | 保留各代理草稿；刷新序号阻止旧 GET 覆盖新保存；提供显式重新加载入口 | 草稿切换、外部更新、延迟 GET 回归 |
| 更换地址/Key 后模型列表过期，迟到响应串入缓存 | 保存版本与草稿连接代数控制缓存；旧响应丢弃；Key 仅保存在当前页面内存 | 同地址凭据版本变化、迟到模型响应、草稿凭据修改 |
| 每次列表请求重复传输长结果 | 列表只返回摘要和字符数；独立接口分页读取当前结果 | 长文本列表大小与分页 HTTP 检查 |
| 复制按钮只复制截断预览 | 提供加载更多和复制完整结果；沿用服务端字符偏移，支持 Unicode | 超过 50,000 字符、非 BMP 字符、失败页重试、真实剪贴板检查 |
| 页面隐藏仍轮询，连接故障持续高频重试 | 可见性控制自动请求，错误指数退避；手动刷新展示更新时间 | 可见性、退避恢复及暂停状态下手动刷新 |
| 任务完成后差异仍是旧预览 | 显示读取时间与可能过期提示；终态自动更新一次，失败保留过期提示和手动重试 | 运行中读取后完成；终态刷新失败不循环重试 |
| 测试成功与保存混淆，初始代理未就绪 | 测试明确不会保存；草稿显示未保存提示；仅在未主动选择且只有一个代理就绪时自动选择 | 测试/保存请求区分及主动选择保留 |
| 辅助文字与状态颜色对比度不足 | 加深辅助文字、placeholder、页脚和绿色状态色 | Edge 五种宽度、三个页面的 axe 扫描 |
| 标签页键盘行为和 ARIA 错误 | 左右键/Home/End；单一 tab 焦点入口；限定代理按钮选择器；选中语义与 fieldset/legend | jsdom 和 Edge 键盘检查；axe 扫描 |
| 整个详情作为 live region | 改为独立简短状态区域，不包含计时器、结果和差异 | DOM 结构检查；人工读屏留作后续验证 |
| 窄屏空态半宽、筛选无匹配文案错误 | 空态跨两列；区分无任务和无匹配并提供清除筛选 | Edge 空态宽度与筛选交互 |
| 多项目任务缺少识别信息 | 列表显示项目名；详情区分源项目和执行目录；搜索包含项目名/路径 | 项目路径筛选回归 |
| 中断任务无结束时间仍持续计时 | 终态缺少可证明的结束时间时显示“—” | 终态计时器回归 |
| 新增文件换行被折叠，差异阅读不便 | 新增文件使用列表，差异可切换换行，工作区路径可复制 | 文件列表回归及浏览器布局检查 |

验证命令见 README「开发与验证」。浏览器使用模拟任务和配置，不访问真实模型服务。自动无障碍扫描覆盖有限的页面状态，不能替代 NVDA/讲述人、操作系统缩放或真实中转服务验证。没有将所有布局优化建议视为缺陷：保留现有双列任务布局，未实施框架迁移、复杂差异高亮或表单重设计。

配置版本校验要求客户端携带最近一次读取的 `revision`，升级后需要重启服务并重新加载面板。历史配置仍可读取；版本元数据不改变 `load_settings()` 的返回字段。
