# 应用设置

顶层标签页为「任务进展」「新建任务」「设置」。设置下分为「连接设置」「选型规则」「运行设置」「界面设置」「存储与归档」，各页使用独立草稿；切换页面保留草稿，刷新浏览器会清除未保存内容。顶层和子标签页都支持方向键、Home、End。

## 可自定义的运行和展示默认值

以下 20 项由 `settings-schema.json` 统一定义范围、默认值和提示，在面板中保存。数值范围用于输入校验，不等同于模型服务商承诺的额度。

| 设置 | 默认值 | 范围 / 选项 | 存储字段 |
| --- | --- | --- | --- |
| 每个服务实例的并发任务数 | 2 | 1–8 | `max_concurrent_tasks` |
| 任务默认最长运行时间（秒） | 600 | 10–86400 | `task_timeout_seconds` |
| 单任务模型调用上限 | 40 | 1–1000 | `max_model_calls` |
| 单任务工具调用上限 | 100 | 1–5000 | `max_tool_calls` |
| Claude 最多交互轮次 | 40 | 1–1000 | `claude_max_turns` |
| DeepSeek 单次输出 token 上限 | 8192 | 128–131072 | `deepseek_max_tokens` |
| 模型列表和基础生成的网络超时（秒） | 45 | 5–300 | `network_timeout_seconds` |
| 面板长操作最长等待时间（秒） | 150 | 10–7200 | `operation_timeout_seconds` |
| 模型列表最多读取页数 | 25 | 1–1000 | `model_catalog_max_pages` |

## 保存与生效

- 应用设置保存在状态目录的 `app-settings.json`，不含凭据；与连接、路由、归档和日志保留配置独立。没有保存过的字段使用原默认值。
- 面板的运行/界面设置分别保存本页字段，使用同一跨进程配置锁、原子写入和版本冲突检查。其他窗口修改后不会用旧草稿覆盖，需重新加载并合并。恢复默认值只填表，保存后才生效。
- 新版服务共享保存值，但并发名额仍按进程分别计算。降低上限不取消已运行任务；满额直接拒绝新任务，没有等待队列。原来加载旧代码的进程需要先重启。
- `AGENT_HUB_MAX_CONCURRENT_TASKS` 保持兼容并优先于保存值。面板显示有效值、覆盖来源及本地保存值并锁定该输入；移除环境覆盖并重启该实例后即可编辑，其他设置仍可保存。
- 任务超时与原生调用预算在提交时形成快照，随 `job.json` 保存；worker 和 SDK 使用同一预算。后续改默认值不会改变已有任务或其进度分母。旧任务使用原预算 40/100，不能套用今天的设置。
- MCP `submit_task` 省略 `timeout_seconds` 时使用保存值，显式传值只覆盖当前任务；`get_job` 省略 `max_chars` 时使用结果分页设置。任务权限与 worktree/direct 仍在每次提交时明确选择。
- 网络、目录分页及 Git 设置供后续操作使用。模型目录达到页数上限仍有后续页时返回错误，不静默返回不完整目录；旧版自动选型在目录失败时继续沿用原有的默认模型回退。目录读取还受操作总时间约束。
- 维护间隔在下一轮维护等待时读取；配置读取和新任务选型仍会检查已启用的本地跟随。
- 面板本地保存后立即更新刷新、分页等设置，页大小改变时回到第一页。其他已打开面板在重新进入设置、任务页或回到窗口时更新。输入过的单次任务超时不会被自动覆盖。
- 默认列表按「运行中 → 最近完成 → 需要关注 → 更早完成」分组。最近完成按结束时间选取并在分页前排序，长任务结束后也会进入靠前区域；数量可设为 0 关闭。最近完成、异常与更早完成组可独立折叠，默认展开，刷新保留折叠状态和当前选择；选择具体状态时直接展开该状态的任务列表。
- 默认结果显示方式用于首次打开的任务，已打开结果保留当前 Markdown/原文模式；复制始终读取完整原文。活动展示条数改变不影响调用统计；已清理日志的旧任务最多显示当时保留的摘要条数。

## 固定值检查范围

此次检查覆盖 `server.py`、`common.py`、三种运行适配器、`events.py`、`progress.py`、工作区、历史/存储、本地同步、规则和面板。操作期限、SDK 预算、用户可见分页与展示数量已集中配置，原有可编辑策略迁入相应设置子页。

仍固定的数值属于内部实现或校验约束：令牌长度及预览有效期、HTTP/JSON 字节边界、路径和文本校验、原子写入重试、进程终止等待、内存缓存容量等。只读工具权限、凭据隔离和工作区安全规则保持原有含义；不会把它们当作偏好开关。活动日志读取上限已按可配置最大模型/工具预算调整，避免提高预算后仍只统计前 2000 行。

## 开发接口

`get_configuration` 在 `app_settings` 下返回 `schema`、`saved_values`、有效 `values`、`overrides` 和 `revision`。受本地令牌和来源校验保护的 `GET api/app-settings` 返回同样快照；`POST api/app-settings` 接收 `{values: {字段: 值}, revision}`，允许部分更新，拒绝未知字段、布尔冒充整数、越界值和旧版本。服务端的顶层 `max_concurrent_tasks` 为兼容字段，取自同一个有效配置快照。
